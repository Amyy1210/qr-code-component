# QR code component

Hi! This is my solution to the [QR code component challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/qr-code-component-iux_sIO_H). I tried my best to make my design match the original as closely as possible.

## Skills that I learned

1. **Flexbox**: I used properties like `justify-content` and `align-items` to center the card on the page, including on mobile screens.
2. **Box shadow**: This was also where I first learned how to use `box-shadow` to create a shadow effect.
